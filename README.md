# FoodLoop Website

A responsive, static HTML/CSS/JavaScript demo for GitHub Pages.

## Publish on GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html` to the repository root.
3. Commit the file to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the public URL shown in Settings → Pages.

## Demo limitations
- This is a front-end prototype. Data is stored in each visitor's browser using localStorage.
- Different visitors do not share listings or reservations.
- Role selection is for demonstration only and is not authentication or access control.
- Safety approval is a demo workflow, not a validated food-safety certification.
- Forecast inputs are illustrative; no live POS, attendance, weather or sensor feed is connected.
- A real multi-user deployment needs a backend (for example Firebase) with server-side authorization and validation.
